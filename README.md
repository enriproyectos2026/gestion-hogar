# 🏠 Gestión Hogar

**El sistema todo-en-uno que centraliza tu casa, tu salud, tus finanzas y tu vida diaria.**

---

## 🎯 ¿Qué es Gestión Hogar?

Deja de usar 15 apps diferentes. **Gestión Hogar** unifica en una sola plataforma todo lo que necesitas para administrar tu hogar:

- 🛒 Compras y despensa
- 💰 Finanzas personales
- 🍳 Recetas y planificación de comidas
- 💊 Salud, medicación y constantes
- 🐾 Mascotas y calendario veterinario
- 🔧 Mantenimiento del hogar
- 🚗 Vehículos
- 📦 Y mucho más...

Todo en un solo lugar. Totalmente privado. Bajo tu control.

---

## ✨ ¿Por qué Gestión Hogar?

| Problema común | Nuestra solución |
|----------------|------------------|
| Datos repartidos en múltiples apps | **Todo centralizado** en un solo sistema |
| Dependencia de la nube de terceros | **Autohospedado** — tus datos, tu servidor |
| Suscripciones mensuales | **Sin costes recurrentes** — código abierto |
| Interfaz compleja y confusa | **Diseño coherente** y fácil de usar |
| Sin integración entre módulos | **Los módulos se conectan** entre sí |

## 🚀 Características que marcan la diferencia

- 🏠 **Multi-casa** — Gestiona varios hogares con esquemas independientes
- 👥 **Multi-usuario** — Roles y permisos para cada miembro de la familia
- ⏰ **Alertas inteligentes** — Caducidades, revisiones, citas...
- 📸 **OCR de tickets** — Importa tickets con foto o PDF
- 📊 **Gráficos y estadísticas** — Visualiza tus datos
- 🖨️ **Fichas imprimibles** — Para cocina, técnicas y más
- 🔒 **100% privado** — Sin dependencias de terceros
- 🧪 **Testeado** — 213 tests de integración, todos pasando
